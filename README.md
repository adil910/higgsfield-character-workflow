# Higgsfield Character & Car Element Workflow

How I build consistent recurring characters and cars in Higgsfield for short AI reels.

By **Adil Imtiaz** · [@by_adilvisuals](https://instagram.com/by_adilvisuals)

## Projects this came from

- **"Ace masked"**: a recurring masked character (black mask with a gold "A", all-black suit, gloves) used in a reel series for a luxury car brand.
- **Revuelto Element**: a car Element trained from about 30 images, used for an 8–9 second concept reel where a miniature car on a windowsill becomes full-size.
